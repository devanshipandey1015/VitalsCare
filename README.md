# VitalsCare

VitalsCare is a secure web application that helps users monitor and manage their health by tracking blood pressure and blood sugar readings over time. The application provides authentication, personalized health records, and an intuitive dashboard for viewing historical data.

---

## Features

- Secure user authentication
- Blood Pressure tracking
- Blood Sugar tracking
- Timestamped health records
- User-specific data isolation
- Responsive dashboard
- Automatic date & time recording
- Clean and intuitive interface

## Getting Started

### Clone the repository

```bash
git clone https://github.com/devanshipandey1015/VitalsCare.git
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file.

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_KEY
```

### Run the application

```bash
npm run dev
```
